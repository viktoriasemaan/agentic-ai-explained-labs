# assets

Diagrams and screenshots referenced by the guides.

Each guide carries an HTML comment marking where a visual belongs. Drop the file
here, then replace the comment with a standard markdown image and alt text.

## Conventions

- Use lowercase, hyphenated filenames.
- Reference with a relative path: `![Alt text](./assets/filename.gif)`
- Always write real alt text describing what the diagram shows, since it is what
  answer engines and screen readers read.
- Keep GIFs under about 10 MB so they load on GitHub without stalling.
